# WavuNet

WavuNet is a fraud intelligence workspace for investigating suspicious financial activity across connected networks.

## Features

- Review prioritized fraud alerts and investigation evidence.
- Manage graph-backed detection rules.
- Search alert, exposure, fraud-ring, and transaction records.
- Ingest transaction events and review their risk signals.

## Run locally

```bash
jac install
jac start --dev main.jac
```
